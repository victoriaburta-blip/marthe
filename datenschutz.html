Was die App auf deinem Gerät speichert

  • Es gibt keine Konten, keine Anmeldung und keine Eingabe von Namen oder E-Mail-Adressen.
  • Dein Lernstand (welche Fragen du wiederholen solltest, die Reihenfolge der letzten Session je Kapitel, Anzahl der Sessions, Streak und das Datum der letzten Session) wird ausschließlich im lokalen Speicher (localStorage) deines Browsers auf deinem Gerät gespeichert.
  • Diese Daten werden nicht an einen Server übertragen – weder an die Verantwortliche noch an GitHub.
  • Damit die App offline funktioniert, werden ihre Dateien im Cache deines Browsers gespeichert (Service Worker).
  • Die App verwendet keine Cookies, keine Analyse- oder Tracking-Dienste und lädt keine Inhalte von fremden Servern. Schriften und Formel-Darstellung sind in der App enthalten.

Die Speicherung auf deinem Gerät ist technisch unbedingt erforderlich, damit die App wie gewünscht funktioniert (§ 25 Abs. 2 Nr. 2 TDDDG).

Fortschritt übertragen

Mit „Fortschritt übertragen“ kannst du einen Code erzeugen, der deinen Lernstand enthält, und ihn auf einem anderen Gerät einfügen. Der Code wird nur auf deinem Gerät erzeugt und nirgendwohin gesendet. Er enthält keine persönlichen Angaben. Was du mit dem Code machst (z. B. ihn dir selbst schicken), entscheidest du.

Löschen deiner Daten

Du kannst alle gespeicherten Daten jederzeit löschen, indem du die Website-Daten dieser Seite in deinen Browser-Einstellungen entfernst oder die App deinstallierst.
